SPT-WBS · Directory-handle persistence check

Test-only diagnostic. Checks whether Microsoft Edge opened from a local file:// page can remember a selected folder handle in IndexedDB and renew permission after reload. It never opens, reads or writes Excel workbooks. Do not choose confidential folders while running diagnostics.

Use a synthetic/disposable folder. Select it with Remember folder, reload this page, then click Reopen remembered folder. The second action tests persistence and user-initiated permission renewal.
