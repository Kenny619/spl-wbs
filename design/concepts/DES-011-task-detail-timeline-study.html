Trade-off: Slightly taller but unambiguous: date track represents time, and completion strip is a separate optional measurement. With missing progress, its reserved spacing prevents layout jump.

Design Office recommendation

  • Recommend Option B if clarity outweighs a few pixels of height; it makes it harder to confuse elapsed schedule time with recorded work completion.
  • If the compact Option A is preferred, use a visible percentage label only for real recorded Progress; a neutral track must never mean 0%.
  • The missing-progress state must remain distinct from recorded 0%. Do not fabricate progress or infer it from TaskStatus, the calendar or the date marker.
  • The remaining-day label uses working-calendar days while displaying only “days,” consistent with the existing approved terminology. These prototype counts are illustrative.
  • The milestone and unscheduled states avoid fabricated start/end dates and meaningless duration bars.
