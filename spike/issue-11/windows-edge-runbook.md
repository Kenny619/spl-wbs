# Issue #11 — actual Windows/Edge test-only runbook

Status: NOT EXECUTED. No production feature implementation is authorized. Prepare an isolated test harness after baseline recovery; the current app has no managed save workflow. Never add write operations to the read-only viewer to run these cases. Use synthetic files only, in a disposable folder. Preserve immutable UI reference/snapshots.

For every case record PASS/FAIL/CONCERN, tester/date, exact Windows 11 build, corporate Edge version/policy, Excel version, file:// URL, packaged harness commit/SHA-256, file location/type (local NTFS versus synced/network), numbered actions, screenshots/video, error names and full original/backup/result SHA-256. Keep only synthetic artifacts. Independent QA reruns critical paths. Localhost results are diagnostic comparisons and must be labeled separately. A feature-presence check alone is insufficient.

|---|---|---|
